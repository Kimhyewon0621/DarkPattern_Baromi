# 로컬 진단 테스트

저장소 루트에서 실행합니다.

```sh
npm run local
```

터미널에 `바로미 로컬 스택이 실행 중입니다`가 표시된 뒤 브라우저에서
`http://localhost:3000/scan/new`를 엽니다. 실행 중인 터미널은 닫지 않습니다.

## 정상 동작 확인

```sh
curl http://localhost:3000/api/v1/health
```

`HTTP 200`과 `"status":"ok"`가 나오면 웹 API가 준비된 상태입니다. 진단을 시작한 뒤에는 워커 터미널에 작업 ID와 오류가 출력되지 않고, 진단 화면의 상태가 `대기`에서 `진행 중`으로 바뀌어야 합니다.

## 포트 충돌

포트 3000이 이미 사용 중이면 `npm run local`은 중복 서버를 만들지 않고 종료합니다. 기존 터미널에서 실행 중인 Next 서버를 `Ctrl-C`로 종료한 뒤 다시 실행합니다.

## 무한 대기 시 확인

1. `/api/v1/health`가 200인지 확인합니다.
2. 워커 프로세스가 같은 `npm run local` 터미널에서 실행 중인지 확인합니다.
3. 진단 화면을 새로고침하지 말고, 터미널에 작업 ID 오류가 있는지 확인합니다.
4. 오류가 있으면 작업 ID와 터미널 마지막 30줄을 함께 보관합니다.

결제·주문 확정·외부 사이트 이동은 실행하지 않습니다. 로그인·OTP·CAPTCHA가 필요한 쇼핑몰은 해당 단계가 미검사로 기록됩니다.
