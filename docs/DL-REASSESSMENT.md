# 딥러닝 필요성 재평가

## 재평가 기준

2026-11-15 기준으로 규칙 엔진과 결정적 경량 분류기가 먼저 처리하고, 모호한 후보만 유료 AI 검토로 보낸다. 합성 회귀 기준선(`npm run classifier:evaluate`)은 4개 범주를 4/4로 분리했고, 미확정 후보 전달률은 25%였다. 이 결과만으로 운영 성능이나 실제 쇼핑몰 일반화 성능을 보증하지 않는다.

## 현재 결정

지금은 DL을 제품 경로에 추가하지 않는다. 현재 병목은 시각 모델의 부재보다 쇼핑몰별 탐색 도달률, 동적 화면의 증거 수집, 승인 테스트몰의 운영 라벨 부족이다. DL 호출은 비용·지연·개인정보 처리면을 늘리므로, 합의된 운영 데이터가 쌓이기 전에는 도입하지 않는다.

## 재검토 트리거

다음 조건을 모두 충족할 때 별도 DL 실험을 연다.

1. 같은 `shopGroupId`를 섞지 않은 validation 그룹 30개 이상과 합의 라벨이 있다.
2. 규칙·경량 분류기·LLM의 불일치 사례를 증거 ID와 함께 분리했다.
3. 시각적 배치·강조·복합 인터랙션처럼 텍스트/DOM 증거만으로 반복적으로 놓치는 유형이 확인된다.
4. DL 후보가 기존 기준선 대비 정상 상점 오탐률, 미검사율, 지연시간, 비용 중 최소 하나를 사전 정의한 한계 이상 개선할 가설을 가진다.

## 실험 게이트

DL 실험은 기존 규칙 판정을 대체하지 않고 shadow mode로만 실행한다. 모델·데이터셋·전처리 버전, 지연시간, 비용, 개인정보 최소화 결과를 기록하고, validation 그룹에서 기존 기준선과 비교한 뒤에만 제품 경로 편입 여부를 결정한다.
